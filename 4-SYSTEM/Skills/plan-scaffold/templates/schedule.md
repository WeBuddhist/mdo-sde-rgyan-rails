# <Plan title> — `<lang>` schedule

The day → verse calendar for this stream. **Generated by
`plan-schedule build`; never typed or edited by hand.** To move a verse between
days use `plan-schedule plan` then `plan-schedule apply`, which ripples the
contiguous ranges and renames the affected day files in the same pass.

Columns:

- **Day** — the absolute session number across the whole plan. No zero-padding.
- **Ch.Day** — the day's ordinal within its chapter.
- **Verses** — a contiguous, gap-free `C.V–C.V` range (or a single `C.V`).
- **Index** — the running verse index across the whole text, used by the
  downstream consumer. `Index − verse` is a constant offset within a chapter;
  `plan-schedule audit` verifies this.
- **Date** — the calendar date this session is delivered.
