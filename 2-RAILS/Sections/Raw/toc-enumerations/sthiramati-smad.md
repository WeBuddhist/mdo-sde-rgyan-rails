Enumeration Block 2:
གོང་དུ་གང་ལ་བསླབ་པ་དང་། ཇི་ལྟར་བསླབ་པ་དང་། གང་གིས་བསླབ་པ་གསུམ་ལས་
Enumeration Block 3:
རང་གི་བྱ་བ་བསྒྲུབ་པ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྤྱི་དང་ཁྱད་པར་རོ། །
Enumeration Block 4:
ད་ཚིགས་སུ་བཅད་པ་གཉིས་ཀྱིས་ལྡང་བའི་ཐབས་བསྟན་ཏེ། དེ་ཡང་རྣམ་པ་གཉིས་ལས་བསླང་བའི་ཐབས་བསྟན་ཏོ། །རྣམ་པ་གཉིས་ནི་ཐེག་པ་ཆེན་པོ་ལ་སྐྱོ་པ་ལས་བསླང་བ་དང་། ཐེག་པ་གཞན་དུ་ལྟུང་བ་ལས་བསླང་བའོ། །
Enumeration Block 5:
གོང་དུ་བསླབ་པ་གཉིས་ཏེ། སྤྱི་དང་ཁྱད་པར་རོ་
Enumeration Block 6:
སྤྱི་དོན་རྣམ་པ་བཅུས་ཕ་རོལ་ཏུ་ཕྱིན་པ་འཆད་དེ་དེ་ནི་གྲངས་ལ་སོགས་པའོ། །
Enumeration Block 7:
གྲངས་རྣམ་པར་དབྱེ་བའི་ཚིགས་སུ་བཅད་པ་རྣམ་པ་དྲུག་སྟེ་
Enumeration Block 8:
མཚན་ཉིད་རྣམ་པར་དབྱེ་བའི་ཚིགས་སུ་བཅད་པ་དྲུག་སྟེ་
Enumeration Block 9:
དེ་ལ་སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། མི་མཐུན་པའི་ཕྱོགས་སྤངས་པའི་མཚན་ཉིད་དང་། རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་ཀྱིས་ཟིན་པའི་མཚན་ཉིད་དང་། འདོད་པ་ཐམས་ཅད་ཡོངས་སུ་རྫོགས་པར་བྱེད་པའི་མཚན་ཉིད་དང་། སེམས་ཅན་རྣམས་པར་སྨིན་པའི་མཚན་ཉིད་དོ། །

Enumeration Block 1:
དེ་ལ་སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་མཚན་ཉིད་ནི་རྣམ་པ་བཞི་སྟེ། མི་མཐུན་པའི་ཕྱོགས་སྤངས་པའི་མཚན་ཉིད་དང་། རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་ཀྱིས་ཟིན་པའི་མཚན་ཉིད་དང་། འདོད་པ་ཐམས་ཅད་ཡོངས་སུ་རྫོགས་པར་བྱེད་པའི་མཚན་ཉིད་དང་། སེམས་ཅན་རྣམས་པར་སྨིན་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 2:
གོ་རིམས་ཇི་ལྟར་བཀོད་ཅེ་ན། རྒྱུ་རྣམ་པ་གསུམ་གྱི་ཕྱིར་གོ་རིམས་དེ་ལྟར་བཀོད་དོ་ཞེས་བསྟན་པའི་ཕྱིར་ཚིགས་སུ་བཅད་པ་གཅིག་རྩོམ་མོ། །
Enumeration Block 3:
སྦྱིན་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ལ་བསྒོམ་པ་རྣམ་པ་ལྔ་ལྟར་བསྒོམ་སྟེ། ལྔ་ནི་དངོས་པོ་ལ་གནས་ཏེ་བསྒོམ་པ་དང་། ཡིད་ལ་བྱེད་པ་ལ་གནས་ཏེ་བསྒོམ་པ་དང་། དེ་བཞིན་དུ་བསམ་པ་ལ་གནས་ཏེ་བསྒོམ་པ་དང་། ཐབས་ལ་གནས་ཏེ་བསྒོམ་པ་དང་། དབང་ཡོད་པ་ལ་གནས་ཏེ་བསྒོམ་པའོ། །དེ་ལ་དངོས་པོ་ལ་གནས་ཏེ་བསྒོམ་པ་རྣམ་པ་བཞིའོ། ། ཡིད་ལ་བྱེད་པ་ལ་གནས་ཏེ་བསྒོམ་པ་རྣམ་པ་བཞིའོ། །བསམ་པ་ལ་གནས་ཏེ་བསྒོམ་པ་རྣམ་པ་དྲུག་གོ། །ཐབས་ལ་གནས་ཏེ་བསྒོམ་པ་རྣམ་པ་གསུམ་མོ། །དབང་ཡོད་པ་ལ་གནས་ཏེ་བསྒོམ་པ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 4:
དངོས་པོ་ལ་གནས་ཏེ་བསྒོམ་པ་ཡང་རྣམ་པ་བཞི་སྟེ། རྒྱུ་ལ་གནས་པ་དང་། རྣམ་པར་སྨིན་པ་ལ་གནས་པ་དང་། སྨོན་ལམ་ལ་གནས་པ་དང་། སོ་སོར་རྟོག་པའི་སྟོབས་ལ་གནས་པའོ། །
Enumeration Block 5:
ཕ་རོལ་ཏུ་ཕྱིན་པ་ཡིད་ལ་བྱེད་པ་ལ་གནས་པ་ནི་རྣམ་པ་བཞི་སྟེ་ཞེས་བྱ་བ་ལ། ཡིད་ལ་བྱེད་པ་ལ་གནས་པ་སྟེ། ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒོམ་པ་རྣམ་པ་བཞི་སྟེ་མོས་པ་ཡིད་ལ་བྱེད་པ་དང་། རོ་མྱང་བ་ཡིད་ལ་བྱེད་པ་དང་། རྗེས་སུ་ཡི་རང་བ་ཡིད་ལ་བྱེད་པ་དང་། མངོན་པར་དགའ་བ་ཡིད་ལ་བྱེད་པའོ། །
Enumeration Block 6:
དེ་ལ་ཆོག་མི་ཤེས་པའི་བསམ་པ་ལ་ཡང་ཆོག་མི་ཤེས་པ་རྣམ་པ་བཞི་སྟེ། དངོས་པོ་གཏོང་བ་ལ་ཆོག་མི་ཤེས་པ་དང་། ལུས་གཏོང་བ་ལ་ཆོག་མི་ཤེས་པ་དང་། དུས་ཆོག་མི་ཤེས་དང་། སེམས་ཅན་ཆོག་མི་ཤེས་པའོ། །
Enumeration Block 7:
ཐབས་ལ་གནས་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་བསྒོམ་པ་རྣམ་པ་གསུམ་སྟེ་ཞེས་བྱ་བ་ལ། ཐབས་ལ་གནས་ནས་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་བསྒོམ་པ་ཡང་རྣམ་པ་གསུམ་ཡོད་དེ། གཏོང་བ་པོ་དང་། རྫས་དང་། ལེན་པ་པོ་མི་དམིགས་པའོ། །
Enumeration Block 8:
ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་ལ་ཕྱེ་ན་དཔག་ཏུ་མེད་པ་ཞིག་ཏུ་འགྱུར་མོད་ཀྱི་དེ་ལ་ཡང་བསྡུས་ཏེ་དབྱེ་ན་ཕ་རོལ་ཏུ་ཕྱིན་པ་རེ་རེ་ཞིང་ཡང་རང་བཞིན་ལ་སོགས་པ་རྣམ་པ་དྲུག་དྲུག་ཏུ་ཤེས་ཏེ།
Enumeration Block 9:
སྦྱིན་པ་ལ་ཕྱེ་ན་རྣམ་པ་གསུམ་དུ་འཇུག་སྟེ། ཆོས་སྦྱིན་པ་ལ་འཇུག་པ་དང་། ཟང་ཟིང་སྦྱིན་པ་ལ་འཇུག་པ་དང་། མི་འཇིགས་པ་སྦྱིན་པ་ལ་འཇུག་པའོ། །
Enumeration Block 10:
འཇུག་པ་ལ་ཡང་རྣམ་པ་གཉིས་སོ། །གང་ཞེ་ན། དབྱེ་བའི་འཇུག་པ་དང་། གཞིའི་འཇུག་པའོ། །དེ་ལ་ཚུལ་ཁྲིམས་ལ་ཕྱེ་ན་རྣམ་པ་གསུམ་དུ་འཇུག་སྟེ། སོ་སོར་ཐར་པའི་སྡོམ་པ་དང་། བསམ་གཏན་གྱི་སྡོམ་པ་དང་། ཟག་པ་མེད་པའི་སྡོམ་པའོ། །
