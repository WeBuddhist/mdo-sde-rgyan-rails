Enumeration Block 1:
ཐེག་པ་ཆེན་པོའི་མདོ་སྡེའི་རྒྱན་གྱི་གཞུང་ཁྱད་འཕགས་འདི་ཉིད་ཤིན་ཏུ་གསལ་བར་གོ་བདེ་བའི་ཚུལ་དུ་རྣམ་པར་བཤད་པ་ལ། མཚན་དོན། འགྱུར་ཕྱག །གཞུང་དོན། མཇུག་དོན་བཞི་ལས།
Enumeration Block 2:
གསུམ་པ་གཞུང་དོན་ལ། ཇི་ལྟར་བརྩམ་པའི་ཚུལ་དང་། དེ་ལྟར་བརྩམས་པའི་བསྟན་བཅོས་ཀྱི་གཞུང་བཤད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་བསྟན་བཅོས་གཞུང་གི་དོན་ལ་བསྒྲུབ་པར་བྱ་བ་དང་། བྱེ་བྲག་ཏུ་ཤེས་པར་བྱ་བ། བསམ་པར་བྱ་བ་དང་། བསམ་གྱིས་མི་ཁྱབ་པ་དང་། བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པའི་ཆོས་རྣམས་ཀྱི་ངོ་བོ་ཉིད་བཤད་པ་དང་ལྔ་ལས། དང་པོ་ཐེག་པ་ཆེན་པོ་བཀར་བསྒྲུབ་པ་ལ། སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས་ལས་
Enumeration Block 4:
གཉིས་པ་ཐེག་ཆེན་བཀར་བསྒྲུབ་པའི་རྣམ་གྲངས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ལོག་པར་རྟོག་པ་ཟློག་བྱེད་ཀྱི་རིགས་པའི་རྣམ་གྲངས་བསྟན་པ་དང་། ཐེག་ཆེན་ལ་ལོག་པར་འཛིན་པ་སྤོང་བར་གདམས་པ་པ་གཉིས།

Enumeration Block 1:
གཉིས་པ་ཐེག་ཆེན་བཀར་བསྒྲུབ་པའི་རྣམ་གྲངས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། ལོག་པར་རྟོག་པ་ཟློག་བྱེད་ཀྱི་རིགས་པའི་རྣམ་གྲངས་བསྟན་པ་དང་། ཐེག་ཆེན་ལ་ལོག་པར་འཛིན་པ་སྤོང་བར་གདམས་པ་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་བྱེ་བྲག་ཏུ་ཤེས་པར་བྱ་བ་ལ། སྐྱབས་འགྲོ་རིགས་སེམས་བསྐྱེད་སྒྲུབ་པ་བཞི་ལས། དང་པོ་ལ། ཁྱད་པར་དང་། ཁྱད་པར་དེ་ལྡན་གྱི་སྐྱབས་འགྲོའི་རང་བཞིན་དོན་བསྡུས་ཏེ་བསྟན་པ་གསུམ། དང་པོ་ལ་ཁྱད་པར་བཞི་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 3:
རྒྱས་བཤད་ལ་གོང་གི་རིམ་པ་བཞིན་བཞི་ལས།
Enumeration Block 4:
ཁས་ལེན་ལ་དངོས་དང་། དཔེས་བསྟན་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་དེའི་ཡོན་ཏན་དཔེས་བསྟན་པ་ལ། རྒྱལ་པོའི་སྲས་ཀྱི་དཔེ་དང་། བློན་པོ་ཆེན་པོའི་དཔེ་གཉིས།
Enumeration Block 6:
གཉིས་པ་རིགས་ཀྱི་ལེའུ་བཤད་པ་ལ་རིགས་ཡོད་པ་བཤད་པ་དང་། རིགས་མེད་པ་བཤད་པ། ཐེག་པ་མཆོག་གི་རིགས་ལ་བསྔགས་པའི་སྒོ་ནས་ལེའུའི་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ་སྡོམ་གྱི་སྒོ་ནས་མདོར་བསྟན། དེ་དག་སོ་སོའི་དོན་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 7:
སྤྱིར་རིགས་ཐ་དད་པ་ཡོད་པ་དང་། དེ་ལས་ཐེག་ཆེན་གྱི་རིགས་མཆོག་ཉིད་ཡིན་པ་དང་། རིགས་ཀྱི་མཚན་ཉིད་དང་རིགས་དེའི་རྟགས་དང་། རིགས་ཀྱི་རབ་ཏུ་དབྱེ་བ་དང་རིགས་སད་པར་མི་བྱེད་པའི་སྒྲིབ་པའམ་ཉེས་དམིགས་དང་། རིགས་ཀྱི་ཕན་ཡོན་དང་། རིགས་ཀྱི་དཔེ་གསེར་དང་རིན་ཆེན་རྣམ་པ་གཉིས་ཏེ། དེ་ལྟར་དོན་བརྒྱད་པོ་སོ་སོ་རེ་རེ་ལའང་རྣམ་པ་བཞི་རེས་འཆད་དོ། །
Enumeration Block 8:
གཉིས་པ་ལ་མདོར་བསྟན་གྱི་རིམ་པ་དང་མཚུངས་པར་བརྒྱད་ལས།

Enumeration Block 1:
རིགས་མེད་པ་ཞེས་བྱ་བ་ཡང་གནས་སྐབས་དེའི་དུས་ན་ཐར་པའི་རྒྱུ་མེད་པས་རིགས་མེད་པ་དང་ནམ་ཡང་ཐར་པ་མི་འཐོབ་པས་རིགས་མེད་པ་གཉིས་ལས།
Enumeration Block 2:
གསུམ་པ་སེམས་བསྐྱེད་པ་ལ། སེམས་བསྐྱེད་ཀྱི་ངོ་བོ། །དབྱེ་བ། དཔེ། ཕན་ཡོན་གྱི་བསྔགས་པ་བཞི་ལས། །
Enumeration Block 3:
གཉིས་པ་སེམས་བསྐྱེད་ཀྱི་དབྱེ་བ་ལ། སའི་གནས་སྐབས་ཀྱི་དབྱེ་བ་དང༌། རྩ་བ་སོགས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་། བརྡ་དང་ཆོས་ཉིད་ཀྱིས་ཐོབ་པའི་སྒོ་ནས་དབྱེ་བ་གསུམ།
Enumeration Block 4:
དོན་དམ་པའི་བྱང་ཆུབ་ཀྱི་སེམས་དེ་སྐྱེ་བ་ཡི་དོན་དང་། རྒྱ་ཆེན་པོའི་དོན་དང༌། དེ་ལ་སྤྲོ་བའི་དོན་དང་། བསམ་པ་ཡང་ནི་དག་པ་ཡི་དོན་དང་། ལྷག་མ་དག་ལ་མཁས་པའི་དོན་དང་། ངེས་པར་འབྱུང་བར་འགྱུར་བའི་དོན་དང་དྲུག་ཏུ་ཤེས་པར་བྱའོ་ཞེས་མདོར་བསྟན་ནས།

Enumeration Block 1:
བཞི་པ་བྱང་ཆུབ་ཀྱི་སེམས་ལ་བསྔགས་པའི་སྒོ་ནས་དེ་འཇུག་པར་གདམས་པར་ཆེར་འོས་སེམས་བསྐྱེད་སོགས་ཚིགས་བཅད་བརྒྱད་ལས།
Enumeration Block 2:
བཞི་པ་སྒྲུབ་པ་བཤད་པ་ལ། དོན་གཉིས་ཕུན་སུམ་ཚོགས་པའི་སྒྲུབ་པ་སྤྱིར་བསྟན། གཞན་དོན་སྒྲུབ་ཚུལ་བྱེ་བྲག་ཏུ་བཤད་པ་བསྒྲུབ་པའི་ཆེ་བ་བསྟན་པས་དོན་བསྡུ་བ་གསུམ།
Enumeration Block 3:
གཉིས་པ་ནགཞན་དོན་སྒྲུབ་ཚུལ་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། གཞན་དོན་ལ་འཇུག་ཚུལ། གཞན་དོན་བྱེད་པའི་དབྱེ་བ། གཞན་དོན་བྱེད་པ་དེ་མཆོག་ཏུ་གྱུར་པ། ཁྱད་པར་འཕགས་པ། རྒྱུན་མི་འཆད་པ། ལོག་སྒྲུབ་ཀྱིས་མི་སྐྱོ་བ་དྲུག་ལས།
Enumeration Block 4:
གསུམ་པ་བསམ་པར་བྱ་བ་ལ། རྟོགས་བྱ་དེ་ཁོ་ན་ཉིད་ལ་བསམ་པ། བསྒྲུབ་བྱ་མངོན་ཤེས་དྲུག་ལ་བསམ་པ། ཡོན་ཏན་ཐམས་ཅད་ཐོབ་པའི་རྒྱུ་རང་རྒྱུད་ཡོངས་སུ་སྨིན་པར་བྱ་བ་ལ་བསམ་པ་གསུམ་ལས། དང་པོ་ལ་དེ་ཁོ་ན་ཉིད་ཀྱི་མཚན་ཉིད་དེ་གཏན་ལ་དབབ་པ་བདག་མེད་གཉིས། དེ་ཇི་ལྟར་རྟོགས་ཚུལ་གྱི་གོ་རིམ་གསུམ།

Enumeration Block 1:
དོན་དམ་པ་གཉིས་སུ་མེད་པ་དེ་དོན་ལྔས་བསྟན་ཏེ། ཡོད་མིན་མེད་མིན་དང་། གཅིག་ཐ་དད་མེད་པ་དང་། སྐྱེ་འཇིག་མེད་པ་དང་། འཕེལ་འབྲི་མེད་པ་དང་། དག་དང་མ་དག་མིན་པ་ལྔའོ།
Enumeration Block 2:

Enumeration Block 4:
མངོན་པར་ཤེས་པའི་ལས་དྲུག་ཅེས་འགྲེལ་ཆེན་གསུངས་ཏེ། མཐོང་བའི་ལས། སྟོན་པའི་ལས། འོད་ཟེར་གྱི་ལས་ངན་སོང་འདྲེན་པ་དང་། བདུད་སྤ་བཀོང་བ་གཉིས། རྣམ་པར་རོལ་པའི་ལས། སྤྲུལ་པའི་ལས་དྲུག་ཏུ་བཤད།

Enumeration Block 6:
བདུན་པ་མངོན་པར་ཤེས་པ་དྲུག་སོགས་ཀྱི་མཐུ་ཐོབ་པའི་ཆེ་བ་བསྔགས་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་ནི། དབང་གི་ཆེ་བ། དགའ་བའི་ཆེ་བ། སྲིད་པར་མི་འཇིགས་པའི་ཆེ་བ་གསུམ་བསྟན་པ།
Enumeration Block 7:
རྒྱུད་ཡོངས་སུ་སྨིན་པ་ལས་འགྲུབ་པས་ན་དེ་བཤད་པ་ལ། རང་སྨིན་པ་དང་། གཞན་སྨིན་པར་བྱེད་པ་གཉིས། དང་པོ་ལ་མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་གསུམ།
Enumeration Block 8:
གསུམ་པ་བདག་ཡོངས་སུ་སྨིན་པ་དང་། སྨིན་པའི་དཔེ་བཤད་པ་གཉིས་ལས།

Enumeration Block 1:
གསུམ་པ་བདག་ཡོངས་སུ་སྨིན་པ་དང་། སྨིན་པའི་དཔེ་བཤད་པ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་སེམས་ཅན་གཞན་སྨིན་པར་བྱེད་ཚུལ་ལ་དབྱེ་བ་དང་། བསམ་པ་དང༌། སྦྱོར་བ་གསུམ་ལས། དང་པོ་དབྱེ་བ་བརྒྱད་དེ
Enumeration Block 3:
གསུམ་པ་སྦྱོར་བའི་ཁྱད་པར་ནི་ཕ་རོལ་ཕྱིན་པ་དྲུག་གིས་སྨིན་པར་བྱེད་པའི་ཚིགས་བཅད་དྲུག་དང་། མཇུག་ཏུ་དོན་བསྡུ་བའི་ཚིགས་བཅད་བཅས་བདུན་ལས་དང་པོ། སྦྱིན་པ་ཅི་ལྟ་བུས་སེམས་ཅན་སྨིན་པར་བྱེད་པ་ནི་ཐམས་ཅད་སྦྱིན་པ་དང་། མཉམ་པར་སྦྱིན་པ་དང་། མི་ངོམས་པར་སྦྱིན་པ་རྣམ་པ་གསུམ་གྱིས་ཏེ།
Enumeration Block 4:
ཡོངས་སྨིན་གྱི་རྗེས་སུ་འབྲས་བུ་བྱང་ཆུབ་ཆེན་པོ་བཤད་པ་ལ། ཐོབ་བྱ་མཐར་ཐུག་ཡིན་པའི་སྒོ་ནས་མདོར་བསྟན། དེའི་རང་བཞིན་རྒྱས་པར་བཤད། དོན་བསྡུས་ཏེ་བླ་ན་མེད་པའི་བྱང་ཆུབ་ལ་དམིགས་ནས་སེམས་བསྐྱེད་པར་གདམས་པ་གསུམ། དང་པོ་དཀའ་སྤྱད་དཔག་མེད་སོགས་ཚིགས་བཅད་གཉིས་དང་། དེ་དག་གི་དོན་བཤད་པའི་ཚིགས་བཅད་བཅས་གསུམ་གྱིས་བསྟན་ཏེ།
Enumeration Block 5:
གཉིས་པ་བྱང་ཆུབ་ཆེན་པོ་དེའི་རང་བཞིན་རྒྱས་པར་བཤད་པ་ལ། ཡོན་ཏན་གྱི་རྣམ་གྲངས་བཅུ་ཡི་སྒོ་ནས་སྤྱིར་བསྟན། ཡོན་ཏན་དེ་ལྡན་གྱི་བྱང་ཆུབ་ཉིད་ངོ་བོ་རྒྱུ་འབྲས་སོགས་རྣམ་བཞག་རྣམ་པ་དྲུག་གིས་བཤད་པ་གཉིས། དང་པོ་ལ་བསམ་གྱིས་མི་ཁྱབ་པའི་ཡོན་ཏན་དང་། དོན་གཉིས་ཕུན་ཚོགས་ཀྱི་ཡོན་ཏན་སྐྱབས་ཀྱི་དམ་པར་གྱུར་པའི་ཡོན་ཏན། གནས་གྱུར་པའི་ཡོན་ཏན། ཀུན་དུ་ཁྱབ་པའི་ཡོན་ཏན། མཛད་པ་རྟོག་མེད་ལྷུན་གྱིས་གྲུབ་པར་འཇུག་པའི་ཡོན་ཏན། ཟབ་མོ་དཔག་པར་དཀའ་བའི་ཡོན་ཏན། སྙིང་པོ་འགྱུར་བ་མེད་པའི་ཡོན་ཏན། འབྱོར་པ་ཚད་མེད་པའི་ཡོན་ཏན། སེམས་ཅན་སྨིན་པར་བྱེད་པའི་ཡོན་ཏན་དང་བཅུ་ལས་དང་པོ་གཉིས་སོ་སོར་བསྟན་པ་ཚིགས་བཅད་རེ་རེ་དང་། ཐུན་མོང་དུ་བཤད་པ་ཚིགས་བཅད་གཅིག་བཅས་ཚིགས་སུ་བཅད་པ་གསུམ་གྱིས་བསྟན་ཏེ།
Enumeration Block 6:
གསུམ་པ་སྐྱབས་ཀྱི་དམ་པར་གྱུར་པའི་ཡོན་ཏན་ལ། བདག་གི་དོན་གྲུབ་པ་དང༌། གཞན་གྱི་དོན་སྒྲུབ་པ་དང་། དེ་གཉིས་ཀྱི་ཕྱིར་སྐྱབས་དཔེ་མེད་པར་བསྒྲུབ་པ་གསུམ།
Enumeration Block 7:
གཉིས་པ་སངས་རྒྱས་ན་སེམས་ཅན་གཞན་ལ་ཡང་སྐྱབས་རྣམ་པ་ལྔ་བྱེད་དེ།
Enumeration Block 8:
གསུམ་པ་ལ་དངོས་དང་སྐྱབས་མཆོག་ཡིན་པ་དང༌། སྐྱབས་ཆེན་པོ་ཡིན་པ་གསུམ་ཚིགས་བཅད་རེ་རེས་བསྟན་ཏེ།
Enumeration Block 9:
བཞི་པ་གནས་གྱུར་པའི་ཡོན་ཏན་ལ། གནས་གྱུར་པ་ཉིད་བཤད་པ་དང་། དེ་ཁྱད་པར་འཕགས་ཚུལ་བསྟན་པ་གཉིས།
Enumeration Block 10:
གཉིས་པ་ལ་སངས་རྒྱས་ཀྱི་གནས་གྱུར་དེ་ཉན་རང་གི་གནས་གྱུར་ལས་ཁྱད་པར་འཕགས་ཚུལ་དང་། དེའི་རབ་དབྱེ་བཅུ། བཤད་པ་གཉིས།
Enumeration Block 11:
ལྔ་པ་ཀུན་དུ་ཁྱབ་པའི་ཡོན་ཏན་ལ། དངོས་དང་དོགས་སྤོང་གཉིས།
Enumeration Block 12:
དྲུག་པ་སངས་རྒྱས་ཀྱི་མཛད་པ་རྟོག་མེད་ལྷུན་གྱིས་གྲུབ་པར་འཇུག་ཚུལ་ཇི་ལྟར་རྡ་དག་སོགས་ཀྱིས་བསྟན་ཏེ། ཆོས་སྟོན་པ། མཛད་པ་སྣ་ཚོགས་སྟོན་པ། རྒྱུན་མི་འཆད་པ་སྐྱེ་འབྲིར་སྣང་ཚུལ་བཞི་ཚིགས་བཅད་བཞིས་བསྟན་ཏེ།

Enumeration Block 4:
གཉིས་པ་ཡེ་ཤེས་བཤད་པ་ལ་མདོར་བསྟན་སོ་སོར་རྒྱས་པར་བཤད། ཡེ་ཤེས་དེ་ལྟ་བུ་ཐོབ་བྱེད་ཀྱི་རྒྱུ་བསྟན། སངས་རྒྱས་ཀྱི་ཡེ་ཤེས་སུ་ལམ་ཐམས་ཅད་མཐར་ཐུག་པར་བསྟན་པ་བཞི་ལས།

Enumeration Block 7:
རྩ་བའི་ས་བཅད་ལྔ་པ་བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པའི་ངོ་བོ་ཉིད་ལ་སྔོན་དུ་འགྲོ་བ་མོས་པ་སོགས་ལེའུ་ལྔ་དངོས་གཞི་ཐབས་ལྡན་སོགས་ལེའུ་བཞི། དེའི་གནས་སྐབས་ཀྱི་ཡོན་ཏན་ཡོན་ཏན་གྱི་ལེའུ་དང་། སྤྱོད་པའི་ས་བཅུ་བཤད་པའི་བར་དང་། མཐར་ཐུག་གི་ཡོན་ཏན་འབྲས་ཆོས་བཤད་པ་བཞི་པོ་འདི་

གཉིས་པ་བྱང་ཆུབ་ཕྱོགས་མཐུན་གྱི་ངོ་བོ་ཉིད་དངོས་ལ། གང་གིས་ཟིན་པར་བྱེད་པ་ཐབས་ལྡན་གྱི་ལེའུ་དང་། ཐབས་དེས་ཟིན་པའི་ཕར་ཕྱིན་དང་བསྡུ་དངོས་ཀྱི་ལེའུ། མཆོད་བརྟེན་ཚད་མེད་ཀྱི་ལེའུ། བྱང་ཆུབ་ཕྱོགས་མཐུན་གྱི་ལེའུ་གསུམ་དང་། དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་གྱི་ལེའུ། དེ་ལ་སྤྱོད་པ་དང་ས་ཡི་གནས་སྐབས་དང་མཐར་ཐུག་གིས་རྣམ་པར་བཞག་པའི་ལེའུ་བཅས་དྲུག་ཡོད་པ་ལས། དང་པོ་ཐབས་ལྡན་གྱི་ལེའུ་འདི་ལ་ཐབས་ཀྱིས་གཟུང་བྱའི་ལས་དང། ཟིན་བྱེད་ཀྱི་ཐབས་རྣམ་པ་གསུམ་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། ཡོངས་སུ་མི་སྐྱོ་བ་དང༌། དམན་ལམ་ཡིད་བྱེད་སྤངས་པ་དང༌། རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་གསུམ་ཚིགས་བཅད་རེ་རེས་བསྟན་ཏེ།
Enumeration Block 3:
གཉིས་པ་ཕར་ཕྱིན་དང་བསྡུ་དངོས་ཀྱི་ལེའུ་འདི་ལ་རང་གི་སངས་རྒྱས་ཀྱི་ཆོས་རྫོགས་པར་བྱེད་པ་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་དང་། སེམས་ཅན་གཞན་སྨིན་པར་བྱེད་པ་བསྡུ་བའི་དངོས་པོ་བཞི་བཤད་པ་དང་། དེ་གཉིས་ཀྱི་(འཇུག་,མཇུག་)བསྡུ་བ་གསུམ་ལས། དང་པོ་ལ་སྡོམ་གྱིས་མདོར་བསྟན། དེའི་དོན་རྒྱས་པར་བཤད་པ་གཉིས་
Enumeration Block 4:
ཐོག་མར་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་གི་ཆོས་ཀྱི་རྣམ་བཞག་བཤད་པ་ལ། ཕར་ཕྱིན་དྲུག་གི་གྲངས་ངེས་པ་དང་། ཕར་ཕྱིན་དེ་ཡི་སོ་སོའི་མཚན་ཉིད་དང་། གོ་རིམས་དང་། སྦྱིན་སོགས་སོ་སོའི་ངེས་པའི་ཚིག་དང་། ཕར་ཕྱིན་གྱི་ཡོན་ཏན་ལ་ཇི་ལྟར་གོམས་པར་བྱ་བའི་ཚུལ་དང། ཕར་ཕྱིན་དྲུག་པོ་དེ་དག་གི་ནང་གི་རབ་ཏུ་དབྱེ་བ་དང་། དཀར་པོའི་ཆོས་ཐམས་ཅད་ཕར་ཕྱིན་དྲུག་ཏུ་བསྡུ་བ་དང་། ཕར་ཕྱིན་རྣམས་ཀྱི་མི་མཐུན་ཕྱོགས་སྤང་བ་དང་། ཕར་ཕྱིན་རྣམས་ཀྱི་ཡོན་ཏན་དང་། སྦྱིན་སོགས་རེ་རེའི་ནང་དུ་ཡང་གཞན་དག་འདུས་པའི་ཚུལ་གྱིས་ཕན་ཚུན་རྣམ་པར་ངེས་པ་དང་། རྣམ་གྲངས་བཅུའི་སྒོ་ནས་འཆད་པ་ཡིན་པར་ཤེས་པར་བྱའོ། །
Enumeration Block 5:
གཉིས་པ་སྡོམ་དོན་དང་མཚུངས་པ་རྣམ་གྲངས་བཅུ་ལས། དང་པོ་གྲངས་ངེས་པར་བཞག་པ། ལོངས་སྤྱོད་དང་ལུས་སོགས་ཚིགས་བཅད་དྲུག་གིས་བསྟན་ཏེ། གྲངས་ངེས་པའི་རྒྱུ་མཚན་རྣམ་པ་བཞི་བསྟན་པ་ལས།

Enumeration Block 1:
གསུམ་པ་ཕར་ཕྱིན་དྲུག་གི་གོ་རིམས་ནི། རྒྱུ་མཚན་གསུམ་གྱིས་ཏེ།
Enumeration Block 2:
ཕར་ཕྱིན་དྲུག་པོ་ཐམས་ཅད་རེ་རེ་ནས་ཀྱང་བསྒོམ་པའམ་གོམས་པར་བྱ་ཚུལ་ནི། དངོས་པོ་ལ་གནས་པའམ་བརྟེན་ཏེ་བསྒོམ་པ་དང་། དེ་བཞིན་དུ་ཡིད་ལ་བྱེད་པ་བརྟེན་ཏེ་བསྒོམ་པ་དང་། བསམ་པ་ལ་བརྟེན་ཏེ་བསྒོམ་པ་དང་ནི། ཐབས་དག་པ་བརྟེན་ཏེ་སྒོམ་པ་དང་། དབང་འབྱོར་བ་ཉིད་ལ་བརྟེན་ཏེ་སྒོམ་པར་བྱེད་པའི་རྣམ་གྲངས་ལྔར་བརྗོད་དོ། །
Enumeration Block 3:
སྦྱིན་པ་ལ་སོགས་པའི་ཕར་ཕྱིན་གྱི་དངོས་པོ་ལ་གནས་ཏེ་བསྒོམ་པ་ལ་རྣམ་པ་བཞི་སྟེ། རྒྱུ་ལ་གནས་པ་དང་། རྣམ་པར་སྨིན་པ་ལ་གནས་པ་དང་། སྨོན་ལམ་ལ་གནས་པ་དང་། སོ་སོར་བརྟགས་པའི་སྟོབས་ལ་གནས་པའོ། །
Enumeration Block 4:
གཉིས་པ་ཡིད་ལ་བྱེད་པ་ལ་བརྟེན་ཏེ་བསྒོམ་པ་ལ་ཡིད་བྱེད་བཞི་སྟེ།
Enumeration Block 5:
གསུམ་པ་བསམ་པ་ལ་བརྟེན་ཏེ་བསྒྲུབ་པ་ལ་རྣམ་པ་དྲུག་སྟེ། ཆོག་མི་ཤེས་པའམ་ངོམས་མི་ཤེས་པའི་བསམ་པ། རྒྱ་ཆེན་པོའི་བསམ་པ་དགའ་བའི་བསམ་པ་ཕན་པའི་བསམ་པ། མ་གོས་པའི་བསམ་པ། དགེ་བའི་བསམ་པའོ། །
Enumeration Block 6:
དང་པོ་ངོམས་མི་ཤེས་པ་ལ་ཡང་རྣམ་པ་བཞི་ཡོད་པ
Enumeration Block 7:
མདོར་བསྡུས་ཏེ་དབྱེ་བ་བྱས་ན་ཕར་ཕྱིན་རེ་རེ་ལ་ཡང་། རང་བཞིན་ལ་སོགས་པ་རྣམ་པ་དྲུག་རེ་དྲུག་རེ་ཡོད་པས
Enumeration Block 8:
སླར་ཡང་ཕར་ཕྱིན་དྲུག་གི་ཡོན་ཏན་རྣམ་པར་དག་པས་ཁྱད་པར་དུ་འཕགས་ཚུལ་དང་། མཆོག་ཏུ་གྱུར་པའི་ཚུལ་བསྟན་པ་དང་། སྦྱིན་པའི་བསྔགས་པས་མཚོན་ནས་བསྟན་པ་དང་། བརྩོན་འགྲུས་ཀྱི་ཡོན་ཏན་བྱེ་བྲག་ཏུ་བཤད་པ་བཞི་ལས།

Enumeration Block 1:
སླར་ཡང་ཕར་ཕྱིན་དྲུག་གི་ཡོན་ཏན་རྣམ་པར་དག་པས་ཁྱད་པར་དུ་འཕགས་ཚུལ་དང་། མཆོག་ཏུ་གྱུར་པའི་ཚུལ་བསྟན་པ་དང་། སྦྱིན་པའི་བསྔགས་པས་མཚོན་ནས་བསྟན་པ་དང་། བརྩོན་འགྲུས་ཀྱི་ཡོན་ཏན་བྱེ་བྲག་ཏུ་བཤད་པ་བཞི་ལས།
Enumeration Block 2:
སྦྱིན་སོགས་ཕར་ཕྱིན་དྲུག་པོ་རེ་རེ་ཡང་མཆོག་རྣམ་པ་བརྒྱད་དང་ལྡན་པས་ན་མཆོག་ཏུ་གྱུར་པ་ཡིན་ནོ། །མཆོག་རྣམ་པ་བརྒྱད་ནི། རྟེན་མཆོག་དང་། གཞིའམ་དངོས་པོ་མཆོག་དང་། རྒྱུ་མཚན་མཆོག་དང་། ཡོངས་བསྔོ་མཆོག་དང་། རྒྱུ་མཆོག་དང་། ཡེ་ཤེས་མཆོག་དང་། ཞིང་མཆོག་དང་། གནས་པ་མཆོག་གོ །
Enumeration Block 3:
བཞི་པ་བརྩོན་འགྲུས་ཀྱི་ཕར་ཕྱིན་གྱི་ཡོན་ཏན་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་མདོར་བསྟན་རྒྱས་བཤད་གཉིས།

Enumeration Block 1:
གཉིས་པ་བསྡུ་དངོས་བཞི་བཤད་པ་ལ། རྣམ་གྲངས་ལྔ་ལས་
Enumeration Block 2:
བཞི་པ་བསྡུ་བཞིའི་དབྱེ་བ་ལ། གཉིས་སུ་བསྡུས་པའི་དབྱེ་བ་དང་། གསུམ་དུ་དབྱེ་བ་གཉིས་ལས་
Enumeration Block 3:
