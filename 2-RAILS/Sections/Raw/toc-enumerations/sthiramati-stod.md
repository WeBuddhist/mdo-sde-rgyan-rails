Enumeration Block 1:
རིགས་དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་གཉིས་ཏེ། རང་བཞིན་ལ་གནས་པ་དང་། ཡང་དག་པར་བསྒྲུབ་པའོ། །
Enumeration Block 2:
ཡང་རྣམ་པ་བཞིས་བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཉན་ཐོས་དང་རང་སངས་རྒྱས་ལས་ཁྱད་པར་དུ་འཕགས་པར་རིག་པར་བྱ་སྟེ། བཞི་པོ་དེ་གང་ཞེ་ན། དབང་པོ་དང་། རབ་ཏུ་སྒྲུབ་པ་དང་། མཁས་པ་དང་། འབྲས་བུའོ། །
Enumeration Block 3:
ཡང་སེམས་བསྐྱེད་པ་དེ་རྣམ་པ་གཉིས་སུ་རིག་པར་བྱ་སྟེ། འབྱུང་བ་དང་འབྱུང་བ་མ་ཡིན་པའོ། །
Enumeration Block 4:
སེམས་བསྐྱེད་ནས་ལྡོག་པ་དེ་ཡང་རྣམ་པ་གཉིས་ཏེ། ཤིན་ཏུ་ལྡོག་པ་དང་། ཤིན་ཏུ་ལྡོག་པ་མ་ཡིན་པའོ། །
Enumeration Block 5:
དེ་ལྟར་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པའི་བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་གང་ཞེ་ན། དེ་ཡང་མདོར་ན་རྣམ་པ་གསུམ་དུ་རིག་པར་བྱ་སྟེ། གང་ལ་བསླབ་པ་དང་། ཇི་ལྟར་བསླབ་པ་དང་། གང་དག་སློབ་པ་སྟེ།
Enumeration Block 6:
དེ་ལ་གང་བྱང་ཆུབ་སེམས་དཔའ་བསླབ་པར་བྱ་ཞེ་ན། གནས་བདུན་ལ་བསླབ་པར་བྱའོ། །གནས་བདུན་པོ་གང་ཞེ་ན། བདག་གི་དོན་དང་། གཞན་གྱི་དོན་དང་། དེ་ཁོ་ནའི་དོན་དང་། མཐུ་དང་། སེམས་ཅན་ཡོངས་སུ་སྨིན་པ་དང་། བདག་ཉིད་སངས་རྒྱས་ཀྱི་ཆོས་ཡོངས་སུ་སྨིན་པ་དང་། བླ་ན་མེད་པ་ཡང་དག་པར་རྫོགས་པའི་བྱང་ཆུབ་པ་སྟེ་གནས་བདུན་ནོ། །
Enumeration Block 7:
བྱང་ཆུབ་སེམས་དཔའ་དེ་ཡང་མདོར་བསྡུ་ན་རྣམ་པ་བཅུར་རིག་པར་བྱ་སྟེ། །རིགས་ལ་གནས་པ་དང་། རབ་ཏུ་ཞུགས་པ་དང་། བསམ་པ་མ་དག་པ་དང་། བསམ་པ་དག་པ་དང་། བསམ་པ་ཡོངས་སུ་མ་སྨིན་པ་དང་། བསམ་པ་ཡོངས་སུ་སྨིན་པ་དང་། ངེས་པ་མ་ཡིན་པར་རྟོག་པ་དང་། ངེས་པར་རྟོག་པ་དང་། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པའོ། །
Enumeration Block 8:
ས་བཅུ་པའི་བྱང་ཆུབ་སེམས་དཔའ་ངེས་པར་གཏོགས་པ་དེ་ལ་ཡང་རྣམ་པ་གཉིས་ཏེ། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པའོ། །
Enumeration Block 9:
བསྟན་བཅོས་འདི་འོག་གཞུག་ཏུ་དོན་གསུམ་བཤད་པར་ཟད་དེ། གསུམ་པོ་གང་ཞེ་ན། བྱང་ཆུབ་སེམས་དཔའི་རིགས་དང་། བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པ་དང་། བྱང་ཆུབ་སེམས་དཔའི་སྤྱོད་པ་ལ་བསླབ་པར་བྱ་བའོ། །
Enumeration Block 10:
ཚིགས་སུ་བཅད་པ་གསུམ་གྱི་དོན་རྣམ་པ་གཉིས་ཤིག་སྟོན་ཏེ་ཇི་ལྟར་ཡོད་པ་དང་། ཇི་སྙེད་ཡོད་པའོ། །
Enumeration Block 11:
དེ་ལ་ཐེག་པ་ཆེན་པོའི་ཆོས་རྣམས་ནི་དོན་རྣམ་པ་ལྔའི་དབང་དུ་བྱས་ནས་བཤད་དེ། ལྔ་གང་ཞེ་ན། བསྒྲུབ་པར་བྱ་བ་དང་། ཤེས་པར་བྱ་བ་དང་། བསམ་པ་དང་། བསམ་གྱིས་མི་ཁྱབ་པ་དང་། ཡོངས་སུ་རྫོགས་པར་ཐུགས་སུ་ཆུད་པའི་དོན་སོ་སོ་རང་གིས་རིག་པ་བྱང་ཆུབ་ཀྱི་ཕྱོགས་ཀྱི་རང་བཞིན་ནོ། །
ཆོས་དེ་ལྔའི་འགྲེལ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཐེག་པ་ཆེན་པོའི་དངོས་པོ་ལྔ་དང་། རང་བཞིན་གསུམ་དང་། གང་ཟག་རྣམ་པར་གཞག་པའོ། །དེ་ལ་ཐེག་པ་ཆེན་པོའི་དངོས་པོ་ལྔ་ནི། མིང་དང་། མཚན་མ་དང་། རྣམ་པར་རྟོག་པ་དང་། དེ་བཞིན་ཉིད་དང་། རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་སོ། །

Enumeration Block 1:
དེ་ལ་ཐེག་པ་ཆེན་པོའི་ཆོས་རྣམས་ནི་དོན་རྣམ་པ་ལྔའི་དབང་དུ་བྱས་ནས་བཤད་དེ། ལྔ་གང་ཞེ་ན། བསྒྲུབ་པར་བྱ་བ་དང་། ཤེས་པར་བྱ་བ་དང་། བསམ་པ་དང་། བསམ་གྱིས་མི་ཁྱབ་པ་དང་། ཡོངས་སུ་རྫོགས་པར་ཐུགས་སུ་ཆུད་པའི་དོན་སོ་སོ་རང་གིས་རིག་པ་བྱང་ཆུབ་ཀྱི་ཕྱོགས་ཀྱི་རང་བཞིན་ནོ། །
ཆོས་དེ་ལྔའི་འགྲེལ་པ་ནི་རྣམ་པ་གསུམ་སྟེ། ཐེག་པ་ཆེན་པོའི་དངོས་པོ་ལྔ་དང་། རང་བཞིན་གསུམ་དང་། གང་ཟག་རྣམ་པར་གཞག་པའོ། །
Enumeration Block 2:
ཡོངས་སུ་གྲུབ་པའི་རང་བཞིན་ལ་རྣམ་པ་གཉིས་ཡོད་དེ། དེ་བཞིན་ཉིད་ཀྱི་རང་བཞིན་དང་། རྣམ་པར་མི་རྟོག་པའི་ཡེ་ཤེས་བྱང་ཆུབ་ཀྱི་ཕྱོགས་ཀྱི་རང་བཞིན་ནོ། །
Enumeration Block 3:
ད་ཇི་ལྟར་ན་ཆོས་རྣམ་པ་ལྔ་གང་ཟག་རྣམ་པར་གཞག་པས་བཤད་ཅེ་ན། འདིས་གང་ཟག་རྣམ་པ་གསུམ་སྣང་སྟེ། མི་ཤེས་པའི་གང་ཟག་དང་། ཐེ་ཚོམ་དུ་གྱུར་པའི་གང་ཟག་དང་། ཕྱིན་ཅི་ལོག་ཏུ་མངོན་པར་ཞེན་པའི་གང་ཟག་གོ། །
Enumeration Block 4:
ལན་དུ་ཚིགས་སུ་བཅད་པ་གསུམ་གྱིས་དཔེ་གསུམ་དང་སྦྱར་ཏེ། ཐེག་པ་ཆེན་པོའི་ཆོས་ལ་ལེགས་པ་དང་ཡོན་ཏན་རྣམ་པ་གསུམ་ཡོད་པར་སྟོན་ཏོ། །ཡོན་ཏན་རྣམ་པ་གསུམ་ནི། སྒྲིབ་པ་སྤོང་བའི་རྒྱུ་དང་། ཕུན་སུམ་ཚོགས་པའི་རྒྱུ་དང་། འཕགས་པའི་ནོར་ལ་སྤྱོད་པའི་རྒྱུའོ། །
Enumeration Block 5:
སངས་རྒྱས་ཀྱི་བཀའ་ཡིན་པའི་གཏན་ཚིགས་རྣམ་པ་བརྒྱད་དུ་དབྱེ་བ་ཚིགས་སུ་བཅད་པ་གཅིག་གིས་སྟོན་ཏོ། །
གཏན་ཚིགས་བརྒྱད་ནི། སྔར་ལུང་མ་བསྟན་པ་དང་། ལྷན་ཅིག་བྱུང་བ་དང་། སྤྱོད་ཡུལ་དུ་མ་ཡིན་པ་དང་། གྲུབ་པ་དང་། ཡོད་པ་དང་། མེད་པ་དང་། གཉེན་པོ་དང་། སྒྲ་གཞན་ཕྱིར་རོ། །

Enumeration Block 1:
སངས་རྒྱས་ཀྱི་བཀའ་ཡིན་པའི་གཏན་ཚིགས་རྣམ་པ་བརྒྱད་དུ་དབྱེ་བ་ཚིགས་སུ་བཅད་པ་གཅིག་གིས་སྟོན་ཏོ། །གཏན་ཚིགས་བརྒྱད་ནི། སྔར་ལུང་མ་བསྟན་པ་དང་། ལྷན་ཅིག་བྱུང་བ་དང་། སྤྱོད་ཡུལ་དུ་མ་ཡིན་པ་དང་། གྲུབ་པ་དང་། ཡོད་པ་དང་། མེད་པ་དང་། གཉེན་པོ་དང་། སྒྲ་གཞན་ཕྱིར་རོ། །

Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 4:
ཡིད་ལ་བྱེད་པ་བཅུ་གཅིག་ཀྱང་ཚིགས་སུ་བཅད་པ་བཞིས་བསྟན་ཏོ། །
Enumeration Block 5:
